# Meeting Protocol System

Система ведения протоколов совещаний, решений и поручений.

## Architecture

- Frontend: HTML, CSS, JavaScript ES modules
- Backend: Node.js, TypeScript, REST API
- Database: PostgreSQL
- Runtime: Docker Compose
